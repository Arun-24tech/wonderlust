# Wanderlust Travel Website

A simple frontend assignment made with HTML, CSS and vanilla JavaScript.

## Project files

- `index.html` — page structure and content
- `css/reset.css` — small browser style reset
- `css/style.css` — colors, layout, responsive styles and cards
- `js/main.js` — mobile menu and active navigation link
- `assets/images/` — hero and destination photos
- `assets/icons/` — small SVG icons
- `design/` — supplied Figma reference screenshots

## Run locally

1. Open this folder in VS Code.
2. Install the **Live Server** extension if it is not installed.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

No npm install, framework, backend, or database is required.

## Reference viewport sizes

The supplied Figma reference images are:
- Mobile: 394 × 4036 px
- Tablet: 772 × 3563 px

Use Chrome DevTools' responsive mode and enter those exact viewport widths when comparing the page. The height of the browser viewport can be set to 850 px or 900 px; the full-page page height is produced by the content.

## Before submission

- Keep the original image proportions. Destination images use a 4:3 aspect ratio.
- The page uses the supplied destination names, prices and sample agency text. Only change them if your assignment asks you to.
- Test the mobile menu and navigation links.
